# Phillip Weinstock

<span class="status-line">📍 Melbourne, AU &middot; status: building things</span>

I'm a software developer and engineer based in Melbourne. I build IoT systems, write embedded software, and publish research on functional programming for connected devices. Wrapping up a degree in Mechatronics Engineering, with a Computer Science degree already under the belt.

I like hard problems things where I get my hands dirty and my brain lit up, low-level code, and things that work in the real world — irrigation systems, sensor networks, satellite payloads.

When I'm not researching or debugging protobufs, I'm probably reading about mathematics and other hard sciences, watching misc documentaries or tinkering with game engines.
