Developed a LoRa-MQTT gateway in both Elixir and C++, benchmarked on single-board computers and ESP32 microcontrollers. Concluded that functional programming has great potential for IoT but needs better supporting libraries and underlying VMs.

*ITNAC — Dec 2023*
Reported on building a LoRa-MQTT gateway using Elixir. Found the functional approach produced more compact code, better concurrency support, and more reliable systems compared to conventional languages.
